# 📄 Resume Screening AI

## Project Overview

This project is an AI-based Resume Screening System that predicts job categories from resumes using Machine Learning and NLP techniques.

## Features

* Resume text classification
* Confidence score display
* Top 3 job category predictions
* Job role matching system
* Interactive Streamlit UI

## Technologies Used

* Python
* Scikit-learn
* NLP (TF-IDF, N-grams)
* Streamlit

## Model

* Random Forest Classifier
* Evaluated using Accuracy, Precision, Recall, F1-score

## How to Run

```bash
pip install -r requirements.txt
python -m streamlit run app.py
```
